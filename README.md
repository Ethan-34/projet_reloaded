# projet_reloaded
go-reloaded est un outil en ligne de commande écrit en Go. Il reçoit deux noms de fichiers : un fichier d’entrée qui contient un texte à corriger, et un fichier de sortie dans lequel écrire le texte corrigé.Entre les deux,le programme applique une série de règles d’édition :conversions de nombres,changements de casse,mise en forme de la ponctuation
